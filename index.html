HOW IT WORKS

Live clock.
Official data.
Clear limits.

The time-use model advances using configured Canadian reference clocks. GitHub Actions refreshes the official build snapshots on a 15-minute schedule, while the browser directly rechecks ECCC weather and Open Government every five minutes when visible. Bank of Canada FX is a daily statistic, so it is checked without pretending to be a live market quote.

03

04

Sum the ten survey-covered provinces and label every limitation.
