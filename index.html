HOW IT WORKS

Live clock.
Official distributions.
Clear limits.

The browser advances the current five-minute survey slice using Canadian local time. GitHub Actions is scheduled every 15 minutes to refresh official population and signal snapshots; GitHub may delay scheduled jobs. On page load, the site also attempts direct read-only checks of the public weather, Open Government and Bank of Canada APIs.

01

Resolve clocks

Convert one instant into each province’s local time.

02

Select survey slot

Use the official weekday/weekend five-minute participation vector.

03

Weight population

Apply current quarterly province estimates and the latest national 15+ share.

04

Combine transparently

Sum the ten survey-covered provinces and label every limitation.
