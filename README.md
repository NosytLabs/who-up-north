# Who Up North?

**What is Canada doing right now?**

Who Up North? is a static data-art site for GitHub Pages. It combines Statistics Canada time-use participation rates with Canadian local clocks and official public-data feeds to create a transparent, continuously moving statistical portrait of Canada.

The site does **not** track people. “Right now” means the current clock is applied to official survey distributions.

## What is real

- **Activity mix:** Statistics Canada Table **45-10-0105-01**, 2022 Time Use Survey, 5-minute participation-rate intervals.
- **Population weights:** Statistics Canada Table **17-10-0009-01**, quarterly population estimates.
- **15+ denominator:** Statistics Canada Table **17-10-0005-01** (`All ages` minus `0–4`, `5–9`, and `10–14`).
- **Weather alerts:** Environment and Climate Change Canada / MSC GeoMet OGC API.
- **Open-data activity:** Open Government Portal CKAN Action API.
- **USD/CAD signal:** Bank of Canada Valet API, latest published daily average.

Nothing in the core counter is generated by an LLM.

## How the static site is “live”

The GitHub Pages workflow downloads the complete official weekday/weekend time-use profile and writes it to `public/data/time-use-profile.json`. That produces **576 official 5-minute slices** (288 weekday + 288 weekend).

The browser then:

1. resolves the current local clock for each province;
2. selects the correct weekday/weekend StatCan five-minute slice;
3. scales it by the latest official population snapshot and national 15+ share;
4. population-weights the ten provincial estimates into a Canadian snapshot.

The core model therefore advances locally without a server. The scheduled Pages workflow refreshes source data twice an hour so population/live-feed snapshots stay fresh. The Time Use Survey itself is a survey profile, not a live sensor feed.

## Jev / TypeSafe System One

Jev is deliberately downstream of the statistics. `scripts/generate-jev-fact.mjs` sends a **closed set of already computed, verified candidate facts** to `typesafe-ai/jev` and asks which is most interesting to feature.

Jev cannot modify counts, percentages, source data, or methodology.

For GitHub Pages, set this repository secret to enable Jev during the Pages build:

```text
AI_GATEWAY_API_KEY
```

Without the secret, the build writes a deterministic fact card and the rest of the site works normally.

## GitHub Pages deployment

The repository includes `.github/workflows/pages.yml`.

On push to `main`, manual dispatch, and twice-hourly schedule it:

```text
refresh official data
→ optionally run Jev
→ run integrity checks
→ build dist/
→ upload GitHub Pages artifact
→ deploy Pages
```

GitHub repository settings should use **GitHub Actions** as the Pages source.

## Local development

The project is intentionally dependency-light. The browser app itself has no framework runtime.

```bash
npm run check
npm run build
npm run preview
```

A local build without `public/data/time-use-profile.json` intentionally shows the fail-closed state. To create fresh data locally, run:

```bash
npm run refresh
npm run jev
npm run build
```

Those refresh commands require network access to the official endpoints.

## Important modelling limits

- Table 45-10-0105-01 is **Canada-level**, not province-specific diary data. Province cards apply the Canadian profile at the province’s local time and population scale.
- The Time Use Survey used here covers the **ten provinces**. Yukon, Northwest Territories and Nunavut are displayed only for time-zone context and are excluded from activity estimates.
- Survey participation rates are estimates and include sampling uncertainty. The source table provides confidence intervals; this visualization currently displays the point estimates.
- Some five-minute cells are suppressed by StatCan. The build never invents the missing component: it substitutes the nearest complete official five-minute vector from the same weekday/weekend series and records that mapping in the generated profile.
- The 15+ proportion is a national share used to align total population estimates with survey scope. It is not a province-specific age adjustment.
- Weather alerts must retain their content/intent; the UI shows short official alert labels and links to the source rather than rewriting warnings.
- Bank of Canada exchange rates are daily indicative averages, **not live market prices**.
